CHẠY TRÊN MÁY: mở thư mục project, chạy:  python -m http.server 8000   rồi vào http://localhost:8000
TRÊN ĐIỆN THOẠI (cùng Wi-Fi): tìm IP máy (ipconfig / ifconfig), vào http://<IP>:8000
SỬA NỘI DUNG: mọi thứ nằm ở đầu script.js (PEOPLE: name, pw, msg, letter, photos; SHARED: ảnh chung; WISHES: lời chúc ở khu vườn).
ẢNH RIÊNG: bỏ ảnh vào assets/images/<tên-không-dấu>/ rồi thêm {src:"...", caption:"..."} vào photos của người đó.
NHẠC: bỏ file vào assets/music/song.mp3 và đặt CONFIG.music.enabled = true.
LƯU Ý: tên/ngày sinh nằm trong script.js nên ai mở mã nguồn cũng đọc được. Chỉ dùng trong nhóm lớp, đừng đăng công khai.
